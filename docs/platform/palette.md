# Colour palette

OpenGP5's colours, used by the website, Launchpad and the web flasher. Contrast ratios are against white
(`#FFFFFF`) and Black (`#090705`); text needs at least 4.5:1.

## Brand

| Name | Hex | Use | On white | On Black |
|---|---|---|---|---|
| Teal | `#3CC0C1` | The brand colour (the banner's "GP5"). Accents, links and focus rings on dark backgrounds | 2.2 | 9.1 |
| Teal light | `#8ADADB` | Hover and diagram text on dark backgrounds | 1.6 | 12.6 |
| Teal dark | `#247475` | Links, buttons and focus rings on light backgrounds | 5.5 | 3.7 |
| Black | `#090705` | The banner's background, dark surfaces, code blocks | | |
| Ink | `#17151B` | Text on light backgrounds | 18.1 | |
| White | `#FFFBFD` | The banner's "Open", text on dark backgrounds | | 19.6 |
| Pedal | `#0F0F1A` | The pedal body in drawings | | |
