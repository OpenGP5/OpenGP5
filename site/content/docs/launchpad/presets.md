## Dreamcatcher

With [Dreamcatcher](../../firmwares/dreamcatcher/) on the pedal, Presets shows a live editor and 8 preset slots.
Live editing needs version **1.2 or later**. Tempo sync (**Free / Sync** and **BPM**) needs **1.4 or later**.
BPM means beats per minute.

### Change and save the sound

1. Turn a control in the live editor to hear the change. Changes made on the pedal also appear here.
2. Use **Save** in the live editor to store the current sound in the active preset.

Changing the live sound does not replace a saved preset until you save it.

### Edit the preset slots

- Name a preset, move it left or right, or clear it.
- **Export** a preset to share it; **Import** loads one from a file.
- Click **Write to pedal** to save the edited slots. This replaces the pedal's set of 8 presets.
- **Undo changes** discards the slot edits and returns to the set read from the pedal.

Save or discard slot edits before using the live editor's **Save** control.
If Launchpad asks you to restart after writing, unplug and reconnect the pedal before saving a preset on it.

## Valeton's firmware

With Valeton's firmware on the pedal, Presets shows its 100 presets. Saving edits needs **V1.0.6**.

1. Select a preset. Edit the order of its effect blocks, the model and settings in each block, or its volume.
2. Enable **Hear it live** to hear edits on the pedal.
3. Click **Save to pedal** to store the preset. **Undo changes** discards the draft edits.

Hearing an edit does not save it. Save before you switch presets or leave the page if you want to keep the change.
You can also rename, reset, export or import one preset. After an import, click **Save to pedal** to store it.

Launchpad reads model names from a copy of Valeton's firmware that it downloads on request.
The app does not include that firmware or its data.

### Clear a group of files

**Clean up the pedal** can clear all 100 presets, all SnapTones or all user IRs.
Read the confirmation and back up or export the data you want to keep before you clear it.
